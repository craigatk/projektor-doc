Stop digging through CI logs to find out why a test failed. Projektor collects your test results,
code coverage, performance trends, and code quality reports from CI into one fast, shareable
dashboard.

[**Full test results**](/docs/introduction/) with stack traces and stdout/stderr for every
failure, [**code coverage**](/docs/code-coverage/) tracked over time,
[**performance test**](/docs/performance-test/) trends so regressions don't sneak in,
[**code quality**](/docs/code-quality/) reports, [**flaky test detection**](/docs/flaky-test/),
[**GitHub PR comments**](/docs/github-pull-request/) linking straight to the relevant results,
and an [**MCP server**](/docs/mcp-server/) so AI coding assistants like Claude Code can query
your test failures directly.

Works with JUnit XML, Jest, and more — publish results with the [Gradle plugin](/docs/gradle-plugin/)
or [Node script](/docs/node-script/), and start browsing in minutes.
